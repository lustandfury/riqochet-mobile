# Padel Tournament — Data Field Definitions Backend reference document for tournament engine V1. Fields marked ❓ require product decision before implementation. --- ## Scoring Formats The `scoring_format` field on Tournament accepts two values: `"regular"` or `"turbo"`. ### Regular - One set per match - First to 6 games wins the set - Tiebreak triggered at 6–6 - Tiebreak: first to 7 points, must win by 2 - Golden point at deuce ### Turbo - One set per match - First to 4 games wins the set - Tiebreak triggered at 3–3 - Tiebreak: first to 7 points, must win by 2 - Golden point at deuce > **Note:** Both formats use a single set. The `set_number` field on Set Score will always be `1` in V1. --- ## 1.
